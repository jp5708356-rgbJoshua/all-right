# 验证说明

已验证：Python3.9.6、macOS26.6 ARM64、Streamlit1.50.0、PyYAML6.0.3。Windows和Python3.12+未验证；跨平台命令不代表实机测试通过。

最近中文显示修订：对账20函数153断言、比价20函数131断言、订单29函数135断言均通过。真实浏览器执行过部分操作，不宣称全量端到端验收。

测试采用标准库unittest和现有Streamlit AppTest，先在临时副本生成合成数据，不读取业务库。tests/baseline_round3a和baseline_round2仅为旧版代码夹具，必须保留，不是另外两套需要启动的应用。

在项目根目录、依赖已安装的虚拟环境中运行：

```bash
python tests/test_reconciliation.py --app . --report-dir /tmp/procurement-reconciliation-results
python tests/test_quotes.py --app . --report-dir /tmp/procurement-quotes-results
python tests/test_orders.py --app . --report-dir /tmp/procurement-orders-results
```

Windows请将报告目录换成本机临时目录，如$env:TEMP下的子目录。报告含输入/预期/实际；故障注入明确标注，不充当自然浏览器复现。

对账台账独立于订单状态。测试真实推进已下单到供应商已确认，并直接比对reconciliation原始行不变。未标记、全0、全部8种布尔组合与级联删除分别覆盖。
